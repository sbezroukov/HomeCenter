Ответы:
Химия изучает вещества, их свойства и превращения. Химические явления — это процессы, при которых из одних веществ образуются другие с новыми свойствами (горение, ржавление). Физические явления не изменяют состав вещества (плавление, испарение). (стр. 8-9)
Физическое тело — это любой предмет окружающего мира. Вещество — то, из чего состоят физические тела. Пример: стакан (тело) изготовлен из стекла (вещество). (стр. 6-7)
Основные методы: наблюдение, эксперимент, моделирование. Химический эксперимент — исследование веществ в контролируемых условиях для изучения их свойств. (стр. 12-14)
Три агрегатных состояния: газообразное (частицы далеко друг от друга, движутся хаотично), жидкое (частицы ближе, есть притяжение, текучесть), твёрдое (частицы в узлах решётки, колеблются). (стр. 15-18)
Чистое вещество имеет постоянный состав и свойства. Смесь — сочетание нескольких веществ. Гомогенные: воздух, раствор соли. Гетерогенные: гранит, смесь песка и воды. (стр. 24-25)
Фильтрование (основано на различии размеров частиц), выпаривание (разная летучесть), дистилляция (разная tкип), действие магнита (магнитные свойства), отстаивание (разная плотность). (стр. 25-28)
Вещества состоят из молекул; 2) Молекулы состоят из атомов; 3) Молекулы и атомы находятся в непрерывном движении; 4) При химических реакциях молекулы разрушаются, атомы перераспределяются. (стр. 33-34)
Химический элемент — вид атомов с одинаковым зарядом ядра. Простое вещество — форма существования элемента в свободном виде. Пример: элемент кислород существует как простые вещества O₂ и O₃. (стр. 30-31)
Аллотропия — способность одного элемента образовывать несколько простых веществ. Примеры: кислород и озон; алмаз, графит, фуллерен (углерод); ромбическая и пластическая сера. (стр. 31-32)
Химический знак обозначает элемент, один атом, относительную атомную массу. Индекс показывает число атомов данного элемента в молекуле или формульной единице. (стр. 35-39)
Химическая формула — обозначение состава вещества с помощью знаков элементов и индексов. Она показывает: индивидуальное вещество, тип вещества, одну формульную единицу, качественный и количественный состав. (стр. 39-41)
Суммируют относительные атомные массы всех атомов в формуле с учётом индексов. M(H₂SO₄) = 2·1 + 32 + 4·16 = 98. (стр. 40-41)
Валентность — свойство атомов соединяться со строго определённым числом атомов другого элемента. Алгоритм: 1) указать известную валентность; 2) найти НОК валентностей; 3) разделить НОК на валентность каждого элемента — получим индексы. (стр. 42-45)
Записать символы элементов; 2) Указать валентности; 3) Найти НОК валентностей; 4) Разделить НОК на каждую валентность — индексы; 5) Записать формулу (индекс 1 не пишут). (стр. 44-45)
Выпадение осадка, выделение газа, изменение цвета, выделение или поглощение тепла, появление запаха. (стр. 47-48)
Масса веществ, вступивших в реакцию, равна массе образовавшихся веществ. Открыт М.В. Ломоносовым и А. Лавуазье. (стр. 51-52)
Химическое уравнение показывает: какие вещества реагируют и образуются; количественные соотношения (по коэффициентам); тип реакции. Составляют, расставляя коэффициенты так, чтобы число атомов каждого элемента слева и справа было равно. (стр. 50-52)
Соединения (из нескольких — одно сложное: 2Mg + O₂ = 2MgO); разложения (из одного — несколько: 2H₂O = 2H₂ + O₂); замещения (простое + сложное → новое простое + новое сложное: Zn + 2HCl = ZnCl₂ + H₂); обмена (два сложных обмениваются частями: NaOH + HCl = NaCl + H₂O). (стр. 54-56)
Катализатор — вещество, ускоряющее реакцию, но не расходующееся в ней. Пример: MnO₂ ускоряет разложение H₂O₂. (стр. 55)
Экзотермические протекают с выделением тепла (горение), эндотермические — с поглощением (разложение известняка). (стр. 48)
Азот ~78%, кислород ~21%, благородные газы ~0,97%, углекислый газ ~0,03%, другие примеси. (стр. 60-61)
Физические: газ без цвета и запаха, мало растворим в воде, тяжелее воздуха. Химические: поддерживает горение, реагирует с металлами и неметаллами. Получение: 2KMnO₄ = K₂MnO₄ + MnO₂ + O₂↑. Распознают тлеющей лучинкой — ярко вспыхивает. (стр. 63-65)
Оксиды — сложные вещества из двух элементов, один из которых кислород. Группы: основные (CaO), кислотные (CO₂), амфотерные (Al₂O₃), несолеобразующие (CO, NO). (стр. 69, 102-104)
Получение: взаимодействие металлов (Zn, Fe) с кислотами (HCl, H₂SO₄): Zn + 2HCl = ZnCl₂ + H₂↑. Распознают по характерному хлопку при поджигании чистого водорода. (стр. 72-74)
Кислоты — сложные вещества из атомов водорода и кислотного остатка. Классификация: по наличию кислорода (H₂SO₄ — кислородсодержащая, HCl — бескислородная); по основности (числу атомов H); по растворимости, летучести, стабильности. (стр. 75-76, 109)
Основания — сложные вещества из атома металла и гидроксогрупп (-OH). Щёлочи — растворимые основания (NaOH, KOH), изменяют окраску индикаторов. Нерастворимые (Cu(OH)₂) — не изменяют индикаторы, разлагаются при нагревании. (стр. 91-92, 106-107)
Соли — сложные вещества из атома металла и кислотного остатка. Группы: средние (NaCl), кислые (NaHCO₃), основные (CuOHCl). (стр. 78, 112-113)
Количество вещества (n) — физическая величина, показывающая число частиц. Моль — количество вещества, содержащее 6,02·10²³ частиц (число Авогадро, Nₐ). (стр. 81-82)
Молярная масса (M) — масса 1 моль вещества. Численно равна относительной молекулярной массе, выражается в г/моль. Связь: n = m/M. (стр. 82-83)
Молярный объём (Vₘ) — объём 1 моль газа. При н.у. (0 °С, 101,325 кПа) Vₘ = 22,4 л/моль. Связь: n = V/Vₘ. (стр. 84-85)
